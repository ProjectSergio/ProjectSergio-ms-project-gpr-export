# MS Project GPR Export

Репозиторий для разработки и сопровождения VBA-макроса выгрузки ГПР из MS Project в Excel.

## Назначение

Макрос предназначен для:

- расчета показателей за выбранный период в MS Project;
- помесячной выгрузки данных в Excel;
- формирования листа всего выбранного периода;
- формирования сводной таблицы;
- построения диаграмм освоения ДС и количества людей;
- сохранения структуры MS Project в Excel с группировками уровней.

## Структура репозитория

```text
/build
    GPR_Export_FULL.bas      # полный файл для копирования в VBA

/src
    UserForm1_Code.bas       # код формы
    modProjectCalc.bas       # расчет периода и ресурсов
    modExcelExport.bas       # выгрузка в Excel
    modSummary.bas           # сводная таблица
    modCharts.bas            # диаграммы
    modHelpers.bas           # общие функции

/docs
    FIELD_MAP.md             # карта полей MS Project
    CHANGELOG.md             # история изменений
```

## Как работать

1. Рабочая версия для быстрого копирования хранится в `/build/GPR_Export_FULL.bas`.
2. Для разработки код постепенно раскладывается по модулям в `/src`.
3. Все изменения фиксируются в `/docs/CHANGELOG.md`.
4. Карта используемых полей MS Project ведется в `/docs/FIELD_MAP.md`.
